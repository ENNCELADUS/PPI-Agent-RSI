## Scientific Agents and Experimental Feedback

- **Virtual Lab — *The Virtual Lab of AI agents designs new SARS-CoV-2 nanobodies*. Nature, 2025.** Integrates scientific agents, protein models, and experimental validation. A precedent for the predictor–agent architecture; its main contribution is scientific workflow orchestration rather than recursive self-improvement. [Paper](https://www.nature.com/articles/s41586-025-09442-9) [Local PDF](../literature/science-agents/2025_virtual_lab.pdf)
- **Co-Scientist — *Accelerating scientific discovery with Co-Scientist*. Nature, 2026.** Uses hypothesis tournaments and meta-review to refine hypotheses and subsequent reasoning. Relevant to candidate ranking and feedback-informed agent instructions. [Paper](https://www.nature.com/articles/s41586-026-10644-y) [Local PDF](../literature/science-agents/2026_co_scientist.pdf)
- **Robin — *A multi-agent system for automating scientific discovery*. Nature, 2026.** Connects candidate generation, laboratory-data analysis, and subsequent hypothesis revision. A biological precedent for an experimental feedback loop, while hypothesis revision is distinct from improvement of the discovery procedure itself. [Paper](https://www.nature.com/articles/s41586-026-10652-y) [Local PDF](../literature/science-agents/2026_robin.pdf)
- **PiEvo — *Principle-Evolvable Scientific Discovery via Uncertainty Minimization*. 2026.** Updates scientific principles using accumulated evidence to guide hypothesis generation and experiment selection. Relevant to learning reusable selection rules. Surrogate-based evaluation should be distinguished from prospective wet-lab validation. [GitHub](https://github.com/amair-lab/PiEvo) [Local PDF](../literature/science-agents/2026_pievo.pdf)

## Agent Workflow Optimization and Recursive Self-Improvement

- **GEPA — *Reflective Prompt Evolution Can Outperform Reinforcement Learning*. ICLR, 2026.** Diagnoses execution trajectories and optimizes prompts through reflection and evaluated search. A foundation for near-term improvements to evidence assessment and candidate-selection instructions. [Paper](https://proceedings.iclr.cc/paper_files/paper/2026/hash/0e9e708b6f48e14fd0ac29e167413f76-Abstract-Conference.html) [Local PDF](../literature/self-improvement/2026_gepa.pdf)
- **ACE — *Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models*. Preprint, 2025.** Maintains evolving playbooks through reflection and incremental curation. Relevant to retaining experimental lessons without retraining the underlying LLM. [Preprint](https://arxiv.org/abs/2510.04618) [Local PDF](../literature/self-improvement/2025_ace.pdf)
- **ADAS / AFlow — *Automated Design of Agentic Systems*; *AFlow: Automating Agentic Workflow Generation*. ICLR, 2025.** Search over agent implementations and executable workflows. Support extending adaptation beyond prompts to tool orchestration and analysis procedures. [Paper](https://proceedings.iclr.cc/paper_files/paper/2025/file/36b7acf6f6010652b3f2a433774a66fe-Paper-Conference.pdf) [ADAS PDF](../literature/self-improvement/2025_adas.pdf) · [AFlow PDF](../literature/self-improvement/2025_aflow.pdf)
- **Darwin Gödel Machine — *Open-Ended Evolution of Self-Improving Agents*. 2025.** Iteratively modifies agent code and evaluates resulting versions. A direct RSI precedent, demonstrated on coding benchmarks rather than sparse biological experiments. [Preprint](https://arxiv.org/abs/2505.22954) [Local PDF](../literature/self-improvement/2025_darwin_godel_machine.pdf)
- **MLE-STAR — *Machine Learning Engineering Agent via Search and Targeted Refinement*. NeurIPS, 2025.** Uses ablation-guided refinement of ML pipeline components. Relevant to automated improvement of predictor fusion, feature processing, and training procedures. [Paper](https://papers.nips.cc/paper_files/paper/2025/hash/a9619dd0f0d54a5cf7734add1dc38cd1-Abstract-Conference.html) [Local PDF](../literature/self-improvement/2025_mle_star.pdf)
- **AlphaEvolve — *A coding agent for scientific and algorithmic discovery*. Technical report, 2025.** Evolves algorithm code against automated evaluators. Supports bounded predictor-design search, with computational screening preceding costly experimental validation. [Preprint](https://arxiv.org/abs/2506.13131) [Local PDF](../literature/self-improvement/2025_alphaevolve.pdf)

## PPI Benchmarks and Feedback-Loop Evaluation

Shortlist of the [public PPI benchmark survey](research-reports/2026-10-19-public-ppi-benchmarks.md) (2026-10-19). Every public PPI label set is retrievable by a web-enabled agent, so these are complements to the private TMP set, run closed-world.

- **PRING — *Rethinking Protein-Protein Interaction Prediction from Pairs to Graphs*. NeurIPS D&B, 2025.** Node-disjoint human test subgraphs with degree-preserving negatives; the protocol-native public PPI track (subgraph = candidate pool, edge set = ground truth). [Preprint](https://arxiv.org/abs/2507.05101) [Local PDF](../literature/ppi/2025_pring.pdf)
- **SKEMPI 2.0 — *An updated benchmark of changes in protein–protein binding energy, kinetics and thermodynamics upon mutation*. Bioinformatics, 2019.** Perturbation track via the component-disjoint split of our `ppi-mutation-ddg` project, recast as ranking disruptive mutations (ΔΔG > 1 kcal/mol). [Paper](https://doi.org/10.1093/bioinformatics/bty635) [Local PDF](../literature/ppi/2019_skempi2.pdf)
- **PPI2Text — *Captioning Protein-Protein Interactions with Coordinate-Aligned Pair-Map Decoding*. Preprint, 2026.** The only published PPI temporal split (annotated after 2025-05-01); a precedent for a CAFA-style post-cutoff IntAct/BioGRID slice. [Preprint](https://arxiv.org/abs/2605.08924) [Local PDF](../literature/ppi/2026_ppi2text.pdf)
- **BioDiscoveryAgent — *An AI Agent for Designing Genetic Perturbation Experiments*. ICLR, 2025.** Pick → reveal → re-rank over replayed CRISPR screens; the mature feedback-loop track with published LLM-agent scores. [Preprint](https://arxiv.org/abs/2405.17631) [Local PDF](../literature/feedback-benchmarks/2025_biodiscoveryagent.pdf)
- **Gupta et al. — *LLMs for Bayesian Optimization in Scientific Domains: Are We There Yet?* EMNLP Findings, 2025** and **Wainrib et al. — *Can AI Scientist Agents Learn from Lab-in-the-Loop Feedback?* Preprint, 2026.** Agents often score the same with permuted labels; every feedback run needs permuted-label and no-feedback arms. [Gupta](https://aclanthology.org/2025.findings-emnlp.838/) [Local PDF](../literature/feedback-benchmarks/2025_llm_bayesian_optimization.pdf) · [Wainrib](https://arxiv.org/abs/2603.26177) [Local PDF](../literature/feedback-benchmarks/2026_lab_in_the_loop_feedback.pdf)
